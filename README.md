# Harbor Academy workspace

Start the app from this folder with `npm.cmd start`, then open **http://localhost:3000**.

The application is in [`technica/`](technica). Runtime requires Node.js 18+ and no package installation.

See the [application README](technica/README.md) for Gemini and Capital One Nessie setup, Money Practice, browser-local progress, architecture, tests, and remaining live verification. The Capital One product must be confirmed before requests are enabled.

To run tests: `npm.cmd --prefix technica ci`, then `npm.cmd test`.
